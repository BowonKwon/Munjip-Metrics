방법·한계

자료

한국고전번역원, 「한국고전번역원_한국문집총간_20240830」(공공데이터포털 3074298, 이용허락범위 제한 없음). 파일 이력 1,251항목 중 채택한 1,249건의 XML zip(첨부 없는 1건·구 스키마 판본 1건 제외) — 문집마다 서지 1파일(저자·집수·간행년·목차·간략해제)과 권차 파일들(편 단위 제목·필자·문체분류·본문). 편(type="최종정보") 단위로 셌다.

한국학중앙연구원, 「조선조문과급제자」(15052752): 문과 급제자 15,151명의 성명·자·호·본관·생년·시험년·등급. 한국학중앙연구원, 「한국역대인명정보」: 27,035명의 성명·자·호·생몰년·본관. 저자 생몰의 교차 확인에 썼다.

세는 단위

모든 수는 편 단위다. 고전번역원 XML 에서 type="최종정보" 인 레벨 요소 하나가 편 하나이고, 전체 637,203편 가운데 609,494편이 저자 자신의 글이다(필자 한자성명 = 서지 저자). 글자는 <내용> 안의 한자 수이며 원주·교감주·난외주 안의 글자를 주로 따로 센다. 검산: 문집 1,249종 전부에서 원본 XML 의 <내용> 재계산과 일치, 문자 참조 잔존 0.

문체

고전번역원이 편마다 붙인 문체분류(대분류 7·중분류 28)를 그대로 쓴다. 사이트가 분류를 고치거나 보태지 않았다. 분류의 품질은 기타류 잔여율(B7)로 보이고, 표본 300편을 제목·본문으로 블라인드 코딩한 일치율을 신뢰도 카드에 적는다(1.0 에서 진행 중이면 그렇게 표시).

세기

XML 에 편 단위 연대가 없어 모든 시계열은 저자 생년의 세기로 묶는다. 저자 활동기와 간행 사이에는 약 1세기의 시차가 있다(곽지은 2026; 간행 시차 D3). 생년이 없는 저자의 문집은 세기 표에서 「생년 미상」 행에 둔다.

저자 묶기

저자 ID 는 한자성명 + 생년이다. 같은 저자의 여러 문집(본집·속집·유고)은 저자 표에서 합산하고 문집 수를 열로 보인다. 필자가 저자와 다른 편(서문·발문·행장·만사·부록)은 저자 저작량에서 뺀다. 같은 이름·같은 생년의 다른 사람은 구별하지 못한다 — 발견되면 overrides 로 고친다.

인물 연결

문과방목 연결 규칙은 M1 성명+생년 일치(중시·발영시로 여러 행이면 첫 급제), M2 성명 일치·방목 생년 없음·자 또는 호 일치, M3 성명 일치·후보 하나·시험년이 생애 안. 둘 이상 남으면 미확정(AMB)으로 두고 연결하지 않는다. 연결률은 급제율이 아니다. 한국역대인명정보는 성명+생년(P1) 또는 성명+호(P2)로 연결해 몰년 일치율만 본다.

관계 문체

서간 수신자는 제목이 答·與·上·寄·復·報·奉·呈·贈·簡·謝 로 시작할 때 그 뒤부터 書·簡·問目·別紙·狀 등 앞까지의 문자열이고, 비지·행장 피장자는 墓誌銘·墓碣銘·神道碑·行狀 등 앞의 문자열(贈·故·先考 등 머리말 제거)이다. 1.0 은 문자열을 사람으로 합치지 않는다 — 자·호·관직으로 달리 불린 같은 사람은 다른 수신자로 센다. 파싱 정밀도는 표본으로 잰다.

알려진 한계

  • XML 의 결함(페이지 번호 불일치·추가·누락·이미지와 한자 불일치, 최지연 외 2021)은 고치지 않았다. 면 번호는 지표로 쓰지 않는다.
  • 「편」의 크기는 편집진의 결정이다. 연작시가 한 편으로 묶인 곳에서는 편 기준 비중이 글자 기준과 달라진다.
  • 고유명사 태그는 문집마다 밀도가 달라(0~100%) 어떤 지표에도 쓰지 않았다.
  • 생년 없는 저자 8명(841편, 저자 글 709)은 A·B 계열 세기 표에 「생년 미상」 행으로 따로 있고, C·D 계열 세기 표에는 없다(그 표의 합은 생년 있는 저자만). 지표 머리의 전체 값(저자 1,248·편 637,203·저자 글 609,494)에는 들어간다.
  • 『호음잡고』(ITKC_MO_0126A)의 冊文類 284편은 제목이 시다(고전번역원 분류의 덩어리 오류). 분류를 고치지 않고 그대로 센 뒤 B 계열 신뢰도 카드에 적었다. 문체분류가 없는 편 88(속편 후반 5종)은 「미분류」로 분모에만 들어간다.
  • 번역문·교감표점 연계는 2024-08 자 XML 의 태그이며 사업 현황과 다를 수 있다.
  • 해석은 하지 않는다. 저자·학파를 평가하는 서술은 없다.

재현

GitHub 저장소의 src/ 에 수집(fetch_itkc.py)·작품 테이블(build_works.py)·검산(check_works.py)·저자 연결(link_authors.py)·지표(metrics_a~d.py)·신뢰도(reliability.py)·사이트(build_site.py) 코드가 있다. 포털 파일 이력은 1,251항목, 내려받은 첨부는 1,250건(운암집 1건은 첨부 없음), 채택한 문집 zip 은 1,249건(구 스키마 중복 1건 제외)이며 그 SHA-256 이 raw_manifest.json 에 있다.

로마자

문집명과 인물 이름은 국어의 로마자 표기법(2000)을 따르되, 성 김·이는 관용 표기 Kim·Yi로 적는다.
