# 문집 메트릭스 — 표본 코딩 코드북 (사전 등록, 2026-11-03)

표본을 뽑기 전에 규칙을 고정한다. 코더에게는 아래 규칙과 표본 파일만 준다. 파싱 결과·연결 결과(`*_key.csv`)는 주지 않는다. 판정을 마친 파일은 `{묶음}_coded.csv` 로 저장하고 `src/reliability.py` 가 정밀도와 윌슨 95% 구간을 계산한다.

## 1. 문체 분류 일치 (`genre_sample.csv`, 300편)

- 질문: 고전번역원이 붙인 대분류 `genre1` 이 이 편의 **제목**(필요하면 고전종합DB 에서 본문 첫 부분)으로 판단한 문체와 맞는가.
- `fits` = `yes` / `no` / `undecided`.
- 기준: 詩類 — 시·부·사·악부 등 운문. 書簡類 — 편지·문목에 답한 글(答·與·上·寄…). 序跋類 — 서·발·증서·제후(題後). 傳記類 — 묘지명·묘갈명·신도비·행장·전·연보·세계. 公車類 — 소·차·계·대책·교서 등 조정 문서. 哀祭類 — 제문·애사·뇌·만사(挽詞가 시 형식이어도 哀祭 로 분류돼 있으면 yes). 雜著類 — 논·설·기·잠·명·찬·송·상량문 등 그 밖의 산문.
- 분류가 명백히 다른 대분류여야 `no`. 경계가 흐린 경우(만사가 詩類 에 있는 등 관행 차이)는 `undecided` 로 두고 note 에 적는다. `undecided` 는 집계에서 `no` 로 센다.

## 2. 서간 수신자 (`letters_sample.csv`, 파싱 300 + 미파싱 60)

- `true_addressee` 에 제목이 가리키는 **수신자 문자열**을 제목에 쓰인 글자 그대로 적는다(자·호·관직·존칭 포함, 띄어쓰기 없음). 예: 「答金晦叔書」 → `金晦叔`, 「上從兄書 判尹公」 → `從兄`, 「與申松溪書 松溪名季誠」 → `申松溪`.
- 수신자가 제목에 없으면(「又答」「又書」「問目」 등) 빈칸으로 둔다.
- 「答○○問目」은 ○○ 을 적는다. 「擬李太白與杜子美書」(의작)은 가상의 발신·수신이므로 빈칸 + note.
- 정밀도 = 파싱된 300편 중 파싱 결과 = 코더 문자열. 재현율 = 수신자가 있는 편(360편 중) 가운데 파싱이 맞힌 비율.

## 3. 비지·행장 피장자 (`epitaphs_sample.csv`, 200편)

- `true_subject` 에 피장자(또는 행장 대상) 문자열을 제목에서 그대로 적되 머리의 贈·故·有明朝鮮(國)·先考·先妣·亡室 등 존칭·관계 접두어는 뺀다. 관직·시호·성·公/君/氏 는 남긴다. 예: 「贈領議政文元李公神道碑銘幷序」 → `領議政文元李公`, 「先妣孺人姜氏遷墓記」 → `孺人姜氏`.
- 제목이 묘지·행장 류가 아니면(선정비·사적기 등) 빈칸 + note.

## 4. 문과방목 연결 (`munkwa_sample.csv`, 연결 200 + 미연결 100)

- 주어지는 것: 저자 성명·생몰·간략해제 본문(`haeje`). 방목 쪽 결과는 주지 않는다.
- `haeje_says_pass` = `yes`(해제가 문과 급제를 말한다) / `no`(급제 언급 없음 또는 생원·진사·음사만) / `unclear`.
- `haeje_exam_year` = 해제가 적은 급제 연도(서기). 「1564년(명종 19) 문과에 장원」처럼 서기년이 있으면 그것을, 왕력만 있으면 환산하지 말고 빈칸 + note 에 원문 표기.
- `haeje_bon` = 해제가 적은 본관(있으면).
- 정밀도(연결 200) = 해제가 급제를 말하고, 연도가 있으면 방목 시험년과 같은 비율. 재현율(미연결 100) = 1 − 해제가 급제를 말하는데 연결되지 않은 비율.

## 5. 공통

- 코더는 원문·해제 이외의 자료(인터넷 검색 포함)를 쓰지 않는다. 판단 근거는 note 에 짧게.
- 코더 묶음은 서로 다른 코더가 맡고, 각 묶음의 10% 를 다른 코더가 블라인드로 다시 코딩해 일치율을 적는다.
